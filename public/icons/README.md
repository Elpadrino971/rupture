# PWA Icons

Pour générer les icônes PWA, utilisez un outil comme:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/

Créez une icône de base (512x512) avec le logo de l'app (🛡️ shield icon)
et générez toutes les tailles requises.

Tailles nécessaires:
- 72x72
- 96x96
- 128x128
- 144x144
- 152x152
- 192x192
- 384x384
- 512x512
